# Local Scout data

Download the public SevAnalysis incidents.csv from https://sevanalysis.com/data/
(CC BY-NC 4.0), and upload it in Scout's sidebar or save it as:

    data/raw/incident_taxonomy/snapshot_2026-10-23/incidents.csv

The directory name is an original snapshot label. Record the real download
date and count when evaluating a newer publisher file.

Scout stores local case history in data/scout_cases.db. Neither the raw dataset
nor the SQLite case database is tracked in GitHub.
Never use private company tickets, secrets or credentials in this prototype.
